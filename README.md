# Россвязь: план нумерации

Учебный проект: PyQt6 + SQLite + pytest. Учёт диапазонов номеров (DEF-код + диапазон),
операторов и регионов; определение оператора и региона по номеру телефона.
Работа с БД идёт через абстрактный интерфейс `NumberingRepository`.

    pip install -r requirements.txt
    python -m app.main      # запуск
    pytest                  # тесты

## Работники и пароли
У каждого работника своя учётная запись (логин + личный пароль, в базе только хэш PBKDF2 с солью).
Самостоятельной регистрации нет: работников добавляет администратор (вкладка «Работники»).
Администратор может сбросить пароль и отключить работника; каждый работник сам меняет свой пароль
кнопкой «Сменить пароль». В таблице диапазонов видно, кто внёс каждый диапазон.

Первый запуск: логин `admin`, пароль `admin` (сразу смените). Демо-данные вымышленные.
Если остался файл `rossvyaz.db` от прошлой версии, он обновится сам (старые учётные записи
не переносятся, создаётся admin/admin).
